## 📚 Formats Supportés

- Copier en texte
- Capture d'écran (PNG)
- Markdown
- HTML
- JSON (format officiel OpenAI, TavernAI/SillyTavern et Ooba)

Utilisez **Tout exporter** pour exporter plusieurs conversations à la fois.

## 📚 Format yang Didukung

- Salin sebagai teks
- Screenshot (PNG)
- Markdown
- HTML
- JSON (format resmi OpenAI, TavernAI/SillyTavern, dan Ooba)

Gunakan **Ekspor Semua** untuk mengekspor banyak percakapan sekaligus.

## 💬 Menggunakan DeepSeek juga?

Coba juga [**DeepSeek Exporter**](https://github.com/pionxzh/deepseek-exporter), proyek serupa dari pengembang yang sama yang menghadirkan ekspor sekali klik untuk [DeepSeek](https://chat.deepseek.com/), termasuk proses penalaran DeepThink dan sumber pencarian web.

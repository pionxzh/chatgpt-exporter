#

## 📚 支援格式

- 複製為文字
- 截圖（PNG）
- Markdown
- HTML
- JSON（OpenAI 官方格式、TavernAI/SillyTavern 和 Ooba）

用「**批量匯出**」一次匯出多個對話。

## 💬 也在用 DeepSeek？

歡迎試試 [**DeepSeek Exporter**](https://github.com/pionxzh/deepseek-exporter)，一樣能一鍵匯出 [DeepSeek](https://chat.deepseek.com/) 的對話，也包含 DeepThink 的推理過程和網路搜尋的來源。
